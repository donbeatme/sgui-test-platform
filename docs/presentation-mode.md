# 展示入口配置

当前前端隐藏测试套件、知识库管理、接口自动化、UI 自动化、任务中心、文件管理及 KEY 管理，并隐藏相关快捷入口与生成 UI 自动化脚本选项。功能代码、路由、权限和数据仍保留。

需要恢复时，在 `Vue/src/config/moduleVisibility.ts` 的 `hiddenModules` 中移除对应键，然后在 `Vue` 目录执行 `npm run build` 并重新部署前端。入口隐藏不替代后端权限控制。

用例 AI 执行仍从「用例管理 → 执行」发起，在「LLM 对话」查看进度，在「执行历史」查看报告。项目管理的系统凭据中可填写统一网站地址；没有单独指定网址的用例共用该地址，公开页面的账号密码可留空。多个不同地址需要在具体用例中明确入口。

执行前检查分为「必须处理」和「建议核查」。缺少入口等配置问题会阻止启动；旧用例缺少新版依据评审记录属于建议核查，不阻止启动。检查通过仅表示配置满足要求，实际通过率以执行报告为准。
